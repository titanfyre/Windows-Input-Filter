# Compatibility

This edition targets keyboard, mouse and compatible HID/XInput/GIP controllers on Windows 10 1709+ and Windows 11 x64.
Compatibility depends on hardware report formats, transport and other installed
drivers. Device enumeration does not itself prove that capture/injection works.
Test the actual hardware and application before deployment. No support for every
model, game or anti-cheat product is claimed. No security-policy bypass is included.

Unknown or unsupported formats retain their normal Windows behavior. Use the
installer diagnostics and the viewer's exact error stage/Windows status to report
a failure. Never force generic parsing onto an unsupported controller report.
